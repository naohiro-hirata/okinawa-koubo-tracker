# 沖縄県 公募・入札発注情報 一覧トラッカー

沖縄県公式サイトの「[公募・入札発注情報](https://www.pref.okinawa.jp/shigoto/nyusatsukeiyaku/1015342/index.html)」
（13の業務カテゴリ）を毎朝8時に自動で取得し、**担当課・金額・募集期間**でソート／絞り込みできる一覧として表示するツールです。

- `scrape.py` … 13カテゴリ×最新年度ページを巡回し、`data.json` を生成
- `index.html` … `data.json` を読み込んで表示する一覧画面（ソート・絞り込み対応）
- `.github/workflows/scrape.yml` … 毎朝8時(JST)に `scrape.py` を実行し、結果を自動コミットするGitHub Actions

同梱の `data.json` は「調達（備品・設備・車両・医薬品など）」カテゴリのみ収録したデモ用サンプルです。
GitHub Actionsを有効化すると、次回実行時に全13カテゴリ分に自動で置き換わります。

---

## 1. 動作確認（ローカル）

```bash
pip install -r requirements.txt
python scrape.py
```

`data.json` が更新されたら、`index.html` をブラウザで直接開くか、簡易サーバーで確認します。

```bash
python -m http.server 8000
# http://localhost:8000/index.html を開く
```

（`file://` で直接開くとブラウザによっては `fetch("data.json")` がブロックされるため、
簡易サーバー経由での確認を推奨します）

## 2. 社内チームに公開する（推奨構成）

### ステップA：GitHubにリポジトリを作る

1. このフォルダの内容をGitHubの新しいリポジトリにpush（社内共有なので **Private** 推奨）
2. リポジトリの Settings → Actions → General → "Workflow permissions" を
   **"Read and write permissions"** に変更（`scrape.yml` が `data.json` をコミットするために必要）

これで毎朝8時(JST)に自動実行され、`data.json` が最新化されます。
（すぐ試したい場合は Actions タブ → "Scrape Okinawa koubo/nyusatsu info" → "Run workflow" で即時実行できます）

### ステップB：チーム閲覧用にホスティングする

無料で社内限定公開する場合、**Cloudflare Pages + Cloudflare Access** が簡単です。

1. [Cloudflare Pages](https://pages.cloudflare.com/) でこのGitHubリポジトリを連携（ビルド設定は不要、静的ファイルのみ）
2. デプロイ後に発行されるURL（例：`okinawa-koubo.pages.dev`）を確認
3. [Cloudflare Zero Trust](https://one.dash.cloudflare.com/) → Access → Applications で
   そのURLを保護対象に設定し、許可するメールアドレス（社内ドメインやアドレス一覧）を指定
   → チームメンバーはメール認証コードでログインしてから閲覧できるようになります（無料枠：50ユーザーまで）

> リポジトリをPrivateにした場合、Cloudflare Pagesとの連携時にGitHub Appのアクセス許可が必要です。
> 社内限定なら十分な構成です。より高度な権限管理（部署ごとの閲覧制限など）が必要な場合は追加で相談してください。

## 3. データの見方・注意点

- **金額**：まず詳細ページ本文から「予定価格」「契約金額」「提案限度額」などの記載を探します。
  本文に無い場合は、添付されている **PDF、またはZIP内のPDF** まで自動で開いて同じキーワードを探します
  （ファイル名に「入札公告」「仕様書」「募集要項」等が含まれるものを優先。1案件あたり最大4ファイルまで、
  15MBを超えるファイルはスキップします）。それでも見つからない場合は `記載なし` と表示されます。
  どこから見つかったかは各金額にマウスオーバーすると表示されます（`amount_source` フィールド）。
  - Word/Excel添付（.docx/.xlsx）は現時点では見に行きません。必要であれば追加対応します。
  - PDF解析には `pdfplumber` を使用しています。画像として埋め込まれたスキャンPDF（OCRされていないもの）は
    テキスト抽出できないため金額を拾えません。
- **締切**：`募集中` の案件は募集期間の終了日を基準に、残り日数を計算して色分け表示します（3日以内=赤、7日以内=黄）。
- **カテゴリ（分類）**：現時点で13カテゴリすべてを対象にしています。「電子入札ポータル（建設工事等）」は別システムのため対象外です。
  必要であれば別途対応も可能です。
- **担当部・担当課**：県サイトの表記（例：`土木建築部　港湾課`）は部等と課等の間が全角スペースで区切られているため、
  最初の空白で「担当部」「担当課」に分割しています。県の[行政機構図](https://www.pref.okinawa.jp/kensei/kencho/1000011/1014102.html)
  はPDF画像のため機械的な突き合わせはしていませんが、県サイト自身の表記ルールに従って分割しているので実務上は問題ないはずです。
  - `沖縄県教育庁` のように課名が書かれていない案件は、担当部＝`沖縄県教育庁`、担当課＝空欄になります。
  - `沖縄県立　◯◯高等学校` のように「県立」だけがまとまるケースがあります（学校名は担当部側ではなく担当課側の情報として扱われます）。
    分類の仕方を変えたい場合は `split_dept()` 関数（`scrape.py`）を調整してください。
- **リンク**：案件名をクリックすると、県サイトの詳細ページが新しいタブで開きます。
- **サイトから消えた案件の扱い**：`scrape.py` は実行ごとに、前回の `data.json` と今回の取得結果を比較し、
  今回見つからなかった（＝県サイトから削除・非掲載になった）案件も `still_listed: false` として残します。
  一覧では薄い表示＋「サイトから削除」バッジで区別され、ツールバーのチェックボックスで表示/非表示を切り替えられます。
  各案件には `first_seen_at`（初めて検出した日時）・`last_seen_at`（最後に県サイト上で見つかった日時）も記録されます。
